# Prompt to Storyboard for Google Flow

A plug-and-play `SKILL.md` that turns any raw idea or one-line prompt into a simple, consistent **10-second storyboard built for Google Flow** (Veo).

Paste the file as the instructions of a Gemini Gem (or as the first message of a new chat), then send only your idea. No setup questions.

## What you get

1. **Lock block** — one short, locked visual identity reused across every shot.
2. **Shot list (10.0s)** — a timecoded plan that adds up to exactly 10 seconds.
3. **Flow prompt** — one paste-ready video prompt for Google Flow, plus optional Gemini keyframe image prompts.
4. **Continuity check** — shot-to-shot consistency verified before you render.

## Install

Copy this folder into your agent's skills directory (folder name matches `name: prompt-to-storyboard-flow`), or paste `SKILL.md` directly into Gemini as described in section 0.

## When to use

Use when the user says storyboard, shot list, scene breakdown, 10-second video, Google Flow, Veo, or reel — or gives an idea and wants a video prompt.
