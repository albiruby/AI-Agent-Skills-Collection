# Subskill 04 — Reference and Identity Consistency

## Purpose
Use image, video, character, product, location, and style references without losing identity.

## Reference roles
Assign each reference a job:
- Identity reference: face, body, character, product identity.
- Model sheet: anatomy, proportions, outfit, multiple views.
- Style reference: rendering, palette, texture, lighting.
- Environment reference: architecture, layout, set dressing.
- Prop reference: exact object design.
- Composition reference: framing and placement.
- Motion reference: movement or performance.

Do not assume one reference establishes every property.

## Authority and conflicts
- Follow the user's explicitly approved reference and latest correction.
- If references conflict, prioritize explicit corrections and the latest approved source.
- Do not silently average incompatible designs.
- Ask for clarification only if the conflict materially blocks the task.

## Multi-character scenes
- Name and describe each character separately.
- Assign a distinct screen position or action to each.
- Preserve silhouette, color, clothing, anatomy, and scale.
- Prevent merging, cloning, recoloring, swapping, or disappearance.
- Keep each character visible long enough to establish identity.

## Asymmetry and anatomy
For asymmetric characters, specify anatomical left/right and anchor the description to the character's own body, not the viewer's screen. Repeat critical asymmetry only where necessary.

For unusual anatomy, state exact counts and relationships. Avoid asking for unnecessary complex movement that exposes the weak point.

## Reference selection
Use the fewest references that adequately establish the desired result. Too many references can create competing signals. Ensure the references are actually uploaded or selected in the target tool; mentioning an ID in text alone may not attach it.

## Output
List each reference, its role, and the non-negotiable attributes it controls.
