# Physics & Interaction Cheatsheet (one page)

## Before generating
1. Tier the shot: R0 none · R1 body only · R2 one contact · R3 multi-step · R4 precision/causal.
2. R3+: split into shots or plan hybrid. R4: do not rely on one take.
3. Fill the interaction spec: part, hand, grip, object state before/after.
4. One hand, large handle, stable surface, medium framing, short clip.

## The sequence (never skip a beat)
approach → align → **contact** → **grip pause** → lift/transfer → carry → place/release → settle

## Prompt sentence formula
`<Subject>'s <anatomical hand> <verb with part> the <named part> of the <object>; the <object> stays still until <contact event>; then <object response that follows the hand>.`

## Verbs
| Prefer | Avoid alone |
|---|---|
| reaches toward, closes her fingers around, lifts, carries, sets down, lets go | grabs, takes, gets, snatches, the object comes to her |

## What to specify
- Named part (top handle, rim, strap)
- Hand (anatomical right/left) and grip (wrap, hook, palm support)
- Object stays at rest until grip
- Weight cue (counterbalance, effort)
- Support after release (bench, table)
- Finger count for stylized characters

## Framing
Medium/medium-wide, static or very slow camera, contact area unobstructed. Avoid extreme macro on fingers and fast camera moves during contact.

## Inspect (checkpoints)
T0 pre-state · T2 pre-contact (object still?) · T3 contact · T4 grip · T5 lift start · T6 carry · T7 release · T8 settle · T9 end

## Immediate rejects
Object moves before touch (A1) · hand passes through (A2) · ghost grip (A4) · object duplicates/vanishes (D1/D2) · finger count wrong at hero beat (B1) · required pour fails (C9)

## Recovery ladder
L0 inputs → L1 resample → L2 clarify prompt → L3 simplify → L4 reframe → L5 split shots → L6 keyframes → L7 other model → L8 hybrid → L9 redesign

## Reliable vs risky (reported; verify per model)
Reliable: ambient motion, light, cloth, simple fluid motion. Risky: contact, state change, shattering, chained physics, long takes.
