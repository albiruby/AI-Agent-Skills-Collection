# Timun Mas example

Shows the suite applied to a real project: a 2D top-down pixel-art game based on Javanese folklore.

- `instruction-slots.md`: three ready-to-paste instruction slots (global rules, character and sprite sheet canon, world/item/VFX/UI canon).
- Pattern to copy (also fully compatible with plug-and-play/FLOW-3-SLOTS.md): every asset prompt = `LOCK STYLE & THEME` first, then `ASSET GENERATION PROMPT`.
- Lessons built into the spec: square cells sized from canvas width / frame count, 65% max character width, fixed feet baseline, flat key-color background, one anchor image per character.
