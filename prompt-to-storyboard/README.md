# Prompt to Storyboard

A plug-and-play `SKILL.md` that turns any raw idea, script, or one-line prompt into a complete, visually consistent storyboard ready for **Gemini image generation**.

Paste the file as the instructions of a Gemini Gem (or as the first message of a new chat), then send only your idea. No setup questions.

## What you get

1. **Story brief** — the idea distilled into purpose, audience, and takeaway.
2. **Style Bible (locked)** — one visual identity: style, palette, lighting, camera language. Reused verbatim in every prompt.
3. **Character reference prompt** — generate this first so characters stay consistent across panels.
4. **Shot list** — every panel with framing, action, and timing.
5. **Image prompts** — one self-contained, paste-ready prompt per panel for Gemini.
6. **Continuity notes + rendering guide** — what must match between shots and how to render in Gemini.

## Install

Copy this folder into your agent's skills directory (folder name matches `name: prompt-to-storyboard`), or paste `SKILL.md` directly into Gemini as described in section 0.

## When to use

Use when the user says storyboard, shot list, panel, scene breakdown, comic, reel/short-video visuals, or ad concept — or gives a story idea and wants images.
