## Routing guidance

- Use `blender-3d-studio-director` for complete projects and cross-discipline orchestration.
- Load one or more specialist skills for focused tasks when the active harness supports skill discovery.
- If skill discovery is unavailable, open the relevant `SKILL.md` directly or follow the matching workflow from the master skill.
- The nested sub-skill workflows described inside specialist files are part of those files; they are not separate installable skills unless a dedicated folder exists.
