# Monetization & Live Ops

## Choose a model (fit to genre & audience)
Premium (one-time), Premium + DLC/expansions, Free-to-play with IAP (cosmetic, convenience, content), Ads (rewarded video, interstitial, banner - rewarded is least intrusive), Hybrid, Subscription/Pass (battle pass, season pass, platform subscription catalogs), Early Access, Pay-what-you-want/itch.io, Crowdfunding, Publisher/funding/grants, Platform deals (portals revenue share), Sponsorship/branded games, Education/B2B licensing.

## Principles
- Monetize **after** the loop is fun; never gate fun behind frustration.
- Avoid pay-to-win in competitive modes; disclose odds for random rewards; respect regional loot-box laws; no dark patterns; strong protections for minors (parental gates, spending limits, no targeted ads for kids).
- Economy: premium currency, pricing ladders, first-purchase offer, store layout, sinks, inflation control (04).
- Ads: frequency caps, placement at natural breaks, mediation (AdMob, AppLovin MAX, Unity LevelPlay), consent (GDPR/UMP, ATT), kids-directed restrictions.

## Live ops
Content calendar (events, seasons, limited-time modes), remote config + feature flags, A/B tests (one variable, sufficient sample), push notification policy (opt-in, value-based), community management (Discord, socials), patch cadence, customer support, refund/chargeback handling, server cost vs revenue model.

## KPIs
D1/D7/D30 retention, DAU/MAU, ARPDAU, ARPPU, conversion rate, LTV vs CPI/CAC (target LTV > CPI), session length/frequency, funnel completion, crash-free rate, wishlist -> sales conversion (PC), review score.

## Output
Model recommendation with revenue assumptions, store/economy design, ad/IAP placement plan, compliance notes, KPI dashboard spec, first 90 days live-ops calendar, analytics event schema.
