# Game Concept & GDD

## Workflow
1. **Elevator pitch** (<=25 words): "A [genre] where you [verb] to [goal], while [twist]."
2. **Design pillars** (3-5): testable statements (e.g. "Every fight is a puzzle"). Use them to veto features.
3. **Core loop**: 30-second (moment-to-moment), 5-minute (session goal), long-term (meta). Draw as `Action -> Feedback -> Reward -> Upgrade -> Harder Action`.
4. **Player fantasy & emotions**: target feelings (mastery, discovery, tension, relaxation, social).
5. **Audience**: age, platform habits, session length, competitors/comps, reference games (3-5) with "what we take / what we change".
6. **USP & differentiation**: why this over the comps.
7. **Scope tiers**: MVP (must), Target (should), Stretch (could), Never (won't).
8. **Milestones**: Prototype -> Vertical Slice -> Alpha (feature complete) -> Beta (content complete) -> Release Candidate -> Live.
9. **Risk register**: design, tech, art, schedule, market; mitigation each.

## GDD template (output as Markdown)
1. Overview (title, genre, platforms, rating target, pitch)
2. Pillars & emotional goals
3. Core loop & game flow (screen flow diagram)
4. Mechanics & rules (link to 04)
5. Controls & camera (link to 13)
6. Content: levels/world (10), story (11), enemies/AI (12), items/economy (04)
7. Art direction & theme (06), audio (09), UI/UX (08)
8. Tech overview (02, 03, 16)
9. Monetization & live ops (18)
10. Production plan, team roles, milestones, budget
11. Metrics for success, risks, open questions

## Quality checks
- Can the core loop be explained in 3 sentences and prototyped in <=2 weeks?
- Does each feature serve a pillar? If not, cut or move to Stretch.
- Is the scope honest for the team size? (Solo: one mechanic done deeply beats ten shallow.)
