# Publishing & Launch

## Pick distribution
Steam, Epic Games Store, GOG, itch.io, Humble, Google Play, App Store, Amazon Appstore, Samsung Galaxy Store, Huawei AppGallery, console storefronts, web portals (CrazyGames, Poki, Newgrounds, Kongregate, GameJolt), Roblox/UEFN, self-hosted (PWA). Verify each store's current fees, rules, review times and requirements before committing.

## Store page assets (create specs list)
Title/subtitle, short + long description (keywords, features bullets), capsule/key art in required sizes, 5+ screenshots showing real gameplay, trailer (15-60 s; gameplay in first 5 s; clear genre; end with call-to-action), GIFs, icon, tags/genres, age rating, languages, system requirements, privacy policy URL, support contact.

## Marketing timeline
- **T-12 to -6 months**: devlog, social presence, Discord, prototype clips/GIFs, store page up early (Steam: collect wishlists), festival demos (Steam Next Fest), influencer/press list.
- **T-3 months**: playable demo, press kit (fact sheet, logo, screenshots, trailer, contact), Steam keys outreach, localization.
- **Launch month**: release date outside big-release crowding, launch discount strategy, day-1 patch ready, community posts.
- **Post-launch**: patch notes, review responses, roadmap, bundles/sales, DLC/updates.

## Build & submission
Versioning (semver + build number), release branch, signed builds, reproducible CI, store-specific packaging (AAB, IPA, Steam depots, itch butler), staged rollout (Play), TestFlight/closed testing requirements, review checklist (crashes, privacy labels, IAP rules, metadata accuracy), rating questionnaires (IARC/ESRB/PEGI).

## Output
Distribution plan, store page copy draft, asset spec checklist, marketing calendar, press kit outline, submission checklist per store, post-launch plan.
