# Game Genre Playbook
For the chosen genre output: **Must-haves / Nice-to-haves / Pitfalls / Typical scope / Best-fit engines / Monetization fit**.

| Genre | Must-haves | Pitfalls / notes |
|---|---|---|
| Platformer (2D/3D) | tight jump physics, coyote time, input buffer, checkpoints, level teaching | floaty/unfair controls, camera |
| Action / Hack&Slash / Beat'em up | hit-stop, combos, enemy telegraphs, crowd AI | animation cancel rules, hitbox clarity |
| Shooter (FPS/TPS/Top-down/Bullet-hell) | recoil/spread, weapon variety, hitscan vs projectile, aim assist for pad | netcode, map flow, aiming on touch |
| Roguelike/Roguelite | run structure, procedural levels, meta-progression, build synergy | balance explosion, RNG fairness |
| Metroidvania | ability-gated map, backtracking, fast travel, map UI | sequence-break QA, map design |
| RPG (JRPG/ARPG/CRPG) | stats, inventory, quests, dialogue, save anywhere | content volume, UI complexity |
| Puzzle / Match-3 / Physics | level curve, hints, undo, star ratings | solvability validation, level count |
| Strategy (RTS/4X/Tower Defense/Turn-based/Auto-battler) | readable UI, pathfinding, fog of war, AI opponent | balance, AI cost, tutorials |
| Simulation / Tycoon / Management / City builder | systems depth, feedback graphs, sandbox, scenarios | UI density, sim performance |
| Survival / Crafting / Sandbox | needs, gathering, base building, persistence | save size, grind |
| Racing / Sports | physics model, AI rubber-banding, tracks/rosters, replays | handling feel, licensing |
| Fighting | frame data, rollback netcode, input buffer, balance | deterministic sim required |
| Adventure / Point&click / Visual novel / Narrative | branching dialogue, flags, save/skip/backlog | writing quality, localization |
| Horror / Stealth | sound design, light/vis, AI perception, pacing | jump-scare overuse, AI fairness |
| Idle / Incremental / Clicker | big-number math, offline progress, prestige | economy walls, monetization ethics |
| Casual / Hyper-casual / Endless runner | 1-input, instant restart, rewarded ads | retention, ad-eCPM dependence |
| Card / Deckbuilder / CCG | rules engine, card data, balance, animations | rules edge cases, anti-cheat if PvP |
| Rhythm / Music | audio latency calibration, chart editor, judgement windows | sync across devices |
| MMO / Battle Royale / MOBA / Extraction | dedicated servers, matchmaking, anti-cheat, live ops | cost/team size: avoid for solo |
| Educational / Serious / Gamification | learning objectives, assessment, progress data | fun vs didactic balance |
| VR/AR/XR | comfort (locomotion, FOV vignette), 72-120 fps, hand tracking | motion sickness, perf |
| Party / Co-op / Social / Cozy | drop-in play, low-stakes, expression | moderation, onboarding |
| Arcade / Retro / Pinball / Casino-style | score chase, juicy loop, leaderboards | regulatory limits (gambling) |

## Output
Genre decision with reasons, feature checklist split MVP/Target/Stretch, 3 reference games with "borrow/avoid", scope warning when genre exceeds team capacity.
