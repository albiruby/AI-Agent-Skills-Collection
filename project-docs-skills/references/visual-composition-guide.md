# Visual Composition Guide for Store & Preview Assets

Follow these layout and typography rules so every generated graphic looks like a studio-crafted launch pack.

## 1. Visual Hierarchy & Scan Speed

- **Eyebrow** (uppercase, muted slate/blue): Category or module context (`POCKET AQUARIUM`, `RUN TO EARN`).
- **Headline** (bold, bright primary accent or crisp white): 3 to 6 words stating the user benefit (`Your tank, on your wrist`).
- **Subtitle** (regular, off-white): 1 concise supporting sentence explaining the concrete mechanism (`3 art styles x 6 themes - switch any time, progress kept`).
- **Device Caption** (bold warm accent, e.g. gold/amber): 2 to 3 words naming the exact mode or screen shown directly above it (`Modern Pixel`, `Minimalist`, `Pseudo-3D`).

## 2. Device Arrangement Rules

- **Hero Overlap (`hero_overlap`)**: Place 3 clean sliced devices in a slight V-overlap on the left (center device 10% larger and in front), with soft drop shadows separating layers, and left-aligned typography on the right 40%.
- **3-Up Feature Showcase (`feature_showcase`)**: Place 3 equal-height clean sliced devices side-by-side along a shared horizontal baseline with generous side margins (at least 8% of canvas width) and centered captions underneath.
- **Cover (`cover`)**: Center 1 hero device at ~65% canvas height with bold title + tight tagline below.

## 3. Contrast & Palette Lock

- Maintain WCAG >= 4.5:1 text contrast against the gradient background.
- Lock **one palette** across the entire asset pack (Cover + Hero + all Feature Screens) so the store listing reads as a unified brand.
- Use subtle geometric corner accents (small hollow squares or dots) at low opacity to frame negative space without competing with the device screen.
