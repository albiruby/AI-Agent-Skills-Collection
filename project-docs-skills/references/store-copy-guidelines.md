# Store Copywriting & Character Limit Guidelines

| Platform | Title Limit | Short Description / Subtitle | Full Description Limit | What's New Limit |
| :--- | :--- | :--- | :--- | :--- |
| **Garmin Connect IQ Store** | 50 chars | Tagline in Hero Banner | ~4,000 chars (plain text + clean bullets) | ~2,000 chars |
| **Apple App Store** | 30 chars | Subtitle: 30 chars; Promo Text: 170 chars | 4,000 chars | 4,000 chars |
| **Google Play Store** | 30 chars | Short Description: 80 chars | 4,000 chars | 500 chars |
| **GitHub Repository** | Repo name | About description: ~160 chars | README.md | GitHub Release Notes |
| **Product Hunt** | 40 chars | Tagline: 60 chars | 260 chars (summary) + Maker comment | N/A |

## Writing Rules

1. Lead with what the user gets in the first 2 lines (above the "Read more" fold).
2. Use concrete nouns and active verbs ("Run to feed, collect, and grow your aquarium") rather than vague adjectives.
3. Keep each bullet to one scannable line starting with a bold or capitalized lead-in.
4. Explain required permissions (GPS, Heart Rate, Storage, Network) plainly so reviewers and users trust the app.

## Verification rule

Character limits and policy text change. Before a store submission, verify the exact current limit and content policy for the destination. If official guidance is unavailable, keep copy within the values above and mark compliance **not verified**.
